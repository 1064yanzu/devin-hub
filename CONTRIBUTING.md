# Contributing

Thank you for helping make Devin Hub useful and reproducible.

1. Open an issue describing a concrete scenario or reproducible problem.
2. Keep PRs focused and include tests for changed behavior.
3. Run `python -m unittest discover -s tests -v` before submitting.
4. Never attach proprietary code, secrets, or production logs to public issues.
5. Distinguish implemented behavior from proposed integrations in documentation.
6. Prefer deterministic observability and evidence before adding model prompts.

This project is experimental and APIs may change without backward-compatibility guarantees.
